# SPORTHUB DAILY — Complete GitHub Pages Starter

Đây là project static HTML/CSS/JS, không cần server.

## Chạy local
Mở `index.html` trực tiếp hoặc dùng Live Server.

## Đưa lên GitHub Pages
1. Tạo repository Public.
2. Upload toàn bộ nội dung bên trong thư mục này, giữ nguyên cấu trúc `assets/css`, `assets/js`, `assets/img`.
3. `Settings → Pages → Deploy from a branch → main → / (root) → Save`.
4. Mở URL GitHub Pages của repository.

## Chỉnh nội dung
- Bài viết và dữ liệu card: `assets/js/content.js`
- Giao diện: `assets/css/style.css`
- Logic tương tác: `assets/js/app.js`
- Ảnh mẫu: `assets/img/`
